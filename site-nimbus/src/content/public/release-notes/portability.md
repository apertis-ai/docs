# Apertis changelog & portability

## Every request leaves a record you can check
- After a request, open **Activity (top bar)** to see that request and its usage.
- Usage reconciles to billing; request evidence when you need it.
- It's a record you can check, not a guarantee.

## Portable: change the baseURL in, change it back out
- OpenAI-compatible: `https://api.apertis.ai/v1` + Apertis key. No lock-in.
- BYOK, or use Apertis open-weight endpoints.
- You set the fallback order on your key.
