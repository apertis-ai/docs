# Rerank API

<aside class="admonition admonition-caution">
<p class="admonition-title">Not currently available</p>

`POST /v1/rerank` is not available on `api.apertis.ai`; requests return HTTP 404 `Invalid URL` (checked 2026-10-06).

</aside>

To order documents by relevance in a retrieval pipeline, compare embedding vectors from the [Embeddings API](/api/embeddings/embeddings-api) instead.
