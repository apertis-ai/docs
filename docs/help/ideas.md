# Ideas — Community Feedback

Apertis includes a built-in community feedback platform where you can submit feature requests, report issues, and vote on proposals that matter to you.

## Features

- **Browse proposals** — View all submissions organized by status: In Progress, Planned, Open, Completed, and Declined
- **Submit new requests** — Create feature requests, model requests, bug reports, and more with category and priority selection
- **Vote** — Upvote proposals you support to help us understand community priorities
- **Discuss** — Leave comments on any proposal to share your thoughts

## Categories

| Category | Description |
|----------|-------------|
| Model Request | Request support for a new AI model |
| Feature Request | Suggest a new platform feature |
| Subscription Plan | Feedback on plans and pricing |
| SDK & Integration | Requests for SDK or tool integrations |
| Bug Report | Report issues or unexpected behavior |
| Other | Anything else |

## Status Workflow

Proposals move through the following stages:

```
Open → Planned → In Progress → Completed
                              → Declined
```

| Status | Meaning |
|--------|---------|
| **Open** | Submitted, awaiting review |
| **Planned** | Approved, scheduled for development |
| **In Progress** | Currently being worked on |
| **Completed** | Shipped |
| **Declined** | Not planned at this time |

## How to Use

1. Sign in to your Apertis account
2. Go to the [Ideas page](https://apertis.ai/ideas)
3. Click **New request** to submit a proposal, or upvote existing ones
4. Click on any proposal to view details and join the discussion
